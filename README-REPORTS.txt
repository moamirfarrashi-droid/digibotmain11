افزونه گزارش مدیریتی همان بات دیجی‌هاینت — نسخه ۱

این افزونه را به ریپازیتوری moamirfarrashi-droid/digibotmain11 اضافه کنید.
بات جدید و توکن جدید لازم نیست. فایل‌های انتشار و سابقه قبلی را تغییر یا پاک نکنید.

نصب فقط از وب:
۱. ZIP را Extract کنید. فایل‌ها داخل ZIP پوشه‌بندی ندارند.
۲. در ریپازیتوری درست، Add file > Upload files را بزنید و تمام فایل‌های استخراج‌شده را آپلود و Commit کنید.
۳. reports.yml را باز کنید و مداد Edit را بزنید. نام فایل بالای ویرایشگر را دقیقاً به این مسیر تغییر دهید:
.github/workflows/reports.yml
سپس Commit changes کنید. این جابه‌جایی ضروری است؛ GitHub ورک‌فلو را از ریشه اجرا نمی‌کند.
۴. در Actions گزینه DigiHinet Admin Reports نمایش داده می‌شود.
۵. در خصوصی همان بات /start یا /help بفرستید؛ یک مدیر کانال باشید.
۶. برای تست اولیه Actions > DigiHinet Admin Reports > Run workflow > main > Run workflow را بزنید.
این اجرا پاسخ خصوصی به دستورهای منتظرمانده را می‌فرستد. پست کانال منتشر نمی‌کند.
۷. حالا /today یا /plan یا /status بفرستید. بات در اجرای بعدی جواب می‌دهد.

گزارش روزانه خصوصی:
۸. هر مدیری که می‌خواهد گزارش خودکار بگیرد، ابتدا در خصوصی بات /id بفرستد و یک اجرای Reports انجام شود.
۹. شناسه عددی برگشتی را در Settings > Secrets and variables > Actions > Secrets با نام زیر بسازید:
TELEGRAM_REPORT_ADMIN_IDS
مقدار برای یک نفر عددی مثل 123456789 است. برای چند نفر با کامای انگلیسی جدا کنید: 123456789,987654321
این اعداد نمونه‌اند؛ شناسه واقعی برگشتی خودتان را وارد کنید.
۱۰. بات بعد از ساعت ۲۲:۳۰ تهران گزارش همان روز را خصوصی می‌فرستد. اگر اجرا به بعد از نیمه‌شب عقب بیفتد، تا ساعت ۶ صبح گزارش روز قبل قابل ارسال است.
فقط افرادی که همچنان مدیر یا مالک کانال هستند گزارش می‌گیرند. هر نفر باید قبلاً به بات Start داده باشد.

تنظیمات موجود مورد استفاده:
Secrets: TELEGRAM_BOT_TOKEN و TELEGRAM_CHANNEL_ID
Variables موجود: ENABLE_POSTING و ENABLE_AI_POSTING و ENABLE_AI_NEWS
برای خاموش کردن دریافت دستورها در Variables مقدار ENABLE_REPORTS را false بگذارید.
برای خاموش کردن فقط گزارش شبانه در Variables مقدار ENABLE_DAILY_REPORT را false بگذارید.
نبودن این دو Variable جدید به معنی روشن بودن گزارش‌هاست؛ ساختنشان برای شروع ضروری نیست.

دستورها در خصوصی بات:
/start یا /help : راهنما
/today : ارسال‌های تأییدشده امروز با لینک پیام
/yesterday : ارسال‌های دیروز
/plan : برنامه امروز؛ موارد گذشته از موعد بدون تأیید جدا می‌شوند
/status : وضعیت روشن/خاموش، شروع کمپین‌ها، تعداد ارسال و pending
/report 2026-11-07 : تاریخ میلادی مشخص
/id : شناسه عددی خود شخص؛ اطلاعات مدیریتی نشان نمی‌دهد
«گزارش امروز» یا «گزارش الان» هم پذیرفته می‌شوند.

نکات دقیق:
این روش دریافت دوره‌ای است، نه پاسخ فوری: ورک‌فلو هر پنج دقیقه درخواست می‌شود ولی GitHub ممکن است بسیار دیرتر اجرا کند یا نوبتی را حذف کند.
اسکریپت کوتاه اجرا و تمام می‌شود؛ سرور دائمی یا اجرای ChatGPT در کار نیست.
با سایر ورک‌فلوهای همین بات هم‌زمان اجرا نمی‌شود تا سابقه‌ها با هم تداخل نکنند.
قابلیت getUpdates را هم‌زمان در سرویس یا نرم‌افزار دیگری با همین توکن استفاده نکنید؛ یک دریافت‌کننده لازم است.
اگر Webhook فعال وجود داشته باشد، اسکریپت خطا می‌دهد و آن را خودسرانه حذف نمی‌کند.
دستورهای بیشتر از ۲۴ ساعت و پیام‌های گروه‌ها پردازش نمی‌شوند.
وضعیت واقعی دریافت روزانه از ثبت پیام‌های بات خوانده می‌شود؛ ثبت در state به معنی موجود بودن فعلی پیام یا نبود همه خطاهای Actions نیست.
گزارش وضعیت pending، وضعیت ارسال نامشخص فعلی را نشان می‌دهد. شماره مدیرها و متن پیام خصوصی در فایل سابقه یا لاگ چاپ نمی‌شود.
سابقه گزارش در telegram-report-state.json به شکل خودکار ساخته می‌شود؛ آن را پاک/صفر نکنید.
پیش از پاسخ، شناسه به‌روزرسانی ذخیره می‌شود؛ پس از قطع ناگهانی ممکن است لازم باشد دستور را دوباره بفرستید. از تکرار خودکار پاسخ جلوگیری می‌شود.
گزارش شبانه پیش از ارسال رزرو می‌شود. اگر ارسال نامشخص شود خودکار تکرار نمی‌شود؛ مدیر می‌تواند /report تاریخ را بفرستد.
گزارش شمارش را از فایل‌های محلی checkout جدید می‌خواند؛ نیازی به API هوش مصنوعی ندارد.
این افزونه هیچ فرمان انتشار/حذف پست و هیچ فرمان خاموش‌کردن کمپین از داخل تلگرام ندارد.
تاریخ کمپین‌های اصلی دست‌نخورده است.

اعتبارسنجی: تست‌های آفلاین برای احراز مدیر، عدم افشای گزارش در گروه، منطقه زمانی، لینک پیام، عدم ارسال تکراری، خطای ذخیره و Webhook در test_telegram_reports.py موجودند.
تست انتهابه‌انتهای تلگرام پس از نصب با توکن واقعی شما انجام می‌شود؛ توکن را در چت ارسال نکنید.
